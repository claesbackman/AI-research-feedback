# <Deck title>

A Quarto reveal.js deck for *<source>*, about <N> minutes plus an appendix.
Open `index.html` in a browser; no server needed. The network is needed only
for the three web fonts, with system fallbacks otherwise.

```
index.qmd                 the deck
plan.md                   the talk script the deck was built from
theme/deck.scss           tokens, faces, layouts, the stage, controls, figure frames
theme/fonts.html          the Google Fonts link
js/lib.js                 drawing helpers and L.DATA, the single home of every charted number
js/deck-charts.js         the stages, drawn at run time
js/include.html           the script tags Quarto appends to the body
figs/convert_figs.sh      PDF → SVG (pdftocairo), then recolour
figs/restyle_figs.py      maps the source's plot colours onto the deck palette
figs/*.svg                generated by convert_figs.sh, committed so the deck renders without poppler; do not edit by hand
shoot_chrome.py           screenshots every slide with the installed Chrome
shoot.py                  the same with playwright, plus an overflow check
_shots/                   screenshot output (gitignored)
```

## Rendering and checking

```sh
quarto render index.qmd        # index.html + index_files/
quarto preview index.qmd       # live reload
python shoot_chrome.py         # _shots/NN.png for every slide, prints console messages
```

Keys while presenting: **S** speaker view (notes), **F** fullscreen, **O**
overview, **E** print view (then print to PDF). `?static` on the URL draws
animated stages finished.

## Conventions

- Four colours carry the argument, aliased in `theme/deck.scss`: **<alias>** = primary <hex>,
  **<alias>** = contrast <hex>, **<alias>** = actor-a <hex>, **<alias>** = actor-b <hex>. Grey is everything else.
- Titles are assertions; read in sequence they are the talk.
- Appendix slides are `visibility="uncounted"`.
- Headings inside slides are `[Text]{.colhead}` or `[Text]{.ph}` spans, never `###`.
- No class is named `.controls`; control rows are `.ctl`.
